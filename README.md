# Licensel

Licensel is an Emacs package that allow developers to insert common LICENSE in the working buffer.

## Current available licenses

- OBSD
- AGPL-3.0-only
- Apache-2.0
- BSD-2-Clause
- BSD-3-Clause
- BSL-1.0
- CCO-1.0
- EPL-2.0
- GPL-2.0-only
- GPL-3.0
- ISC
- LGPL-2.1-only
- LGPLG-3.0-only
- MIT
- MPL-2.0
- Unlicense
- Zlib

## Installation

In emacs do `M-x package-vc-install RET https://github.com/dkdwn/licensel RET` and wait for the package to finish installation.
