# Contributing

First I want to thank you for being interested to contribute to this project.

## How to

First fork the repo. Then follow these commands:

Clone your forked repo:

```bash
git clone https://github.com/<YOUR_USERNAME>/licensel
```

Then add a license by adding the license text and name in the `licenses/` directory.

**Important**

Don't forget to update the README.md by adding you license in the current available licenses list

When it's finished:

Push your changes on your fork

```bash
git add .
git commit -m "Add <license_name>"
git push origin master
```

Go to your repo and open a pull request. The pr will be review by a maintainer as soon as possible.
